1. Kiến trúc tổng thể hệ thống

Toàn bộ hệ thống chạy trong Docker sau Traefik. Người dùng truy cập qua asset.fadoai.com; máy chấm công FA210 giao tiếp 2 chiều — đẩy dữ liệu ADMS qua Traefik (cổng 80/443) và bị poller kéo dữ liệu trực tiếp qua TCP 4370.

Tiến trình nền khởi động cùng server qua instrumentation.ts: (1) ZKTeco poller — kéo dữ liệu chấm công mỗi 30 giây, có watchdog tự phục hồi mỗi 60 giây; (2) Scheduler nhắc gia hạn hợp đồng — chạy 9h/15h; (3) Scheduler đánh giá thử việc — chạy 9h/15h.

2. Luồng xử lý một request chuẩn (kèm kiểm tra quyền RBAC)

Mọi thao tác trên webapp đi qua đúng một con đường: UI → API → kiểm tra quyền → service → database. Đây là pattern bắt buộc của toàn bộ 80+ endpoint.

⚠ Nợ kỹ thuật cần biết: Quyền hiện được đọc từ header x-user-permissions do client tự gửi — có thể bị giả mạo. Đây là placeholder, cần thay bằng cơ chế xác thực session/token phía server. Ngoài ra còn tồn tại 2 hệ auth song song (DB+bcrypt là luồng thật; authStore.ts mock là legacy cần gỡ).

3. Luồng chấm công vân tay realtime

Hai nguồn dữ liệu (máy đẩy ADMS + poller kéo TCP) cùng đổ về bảng device_punches, chống trùng tuyệt đối bằng ON CONFLICT DO NOTHING, rồi tỏa ra 3 nhánh xử lý song song.

Mã chưa map: nếu mã chấm công chưa được gán cho nhân viên nào, punch vẫn được lưu an toàn vào device_punches — chỉ là 3 nhánh dưới không chạy. Khi admin map xong (hoặc luồng push tự map theo employee_code), dữ liệu cũ tự hiện ra, không cần sync lại. Poller có timeout 90 giây chống treo (bug thư viện zklib) và watchdog 60 giây tự khởi động lại khi máy offline.

Quy mô codebase:

  • 19 nhóm trang giao diện (App Router) — toàn bộ tiếng Việt, mobile-first
  • 47 nhóm API · hơn 80 endpoint REST theo pattern chuẩn
  • 60 service nghiệp vụ tại src/lib/services/
  • 97 migration database · bảng plural_snake_case, ID dạng text do app sinh
  • Realtime: Server-Sent Events (SSE) — chấm công, tasks, thông báo

  • Zimbra — quản lý tài khoản email qua SOAP Admin API (tạo/sửa/xóa account, domain)

  • Telegram bot — thông báo cá nhân (chấm công, tasks, tickets)
  • ZKTeco FA210 (SN 2145224860331, IP 115.79.205.119) — chấm công vân tay, hỗ trợ cả pull (TCP 4370) lẫn push (ADMS /iclock)
