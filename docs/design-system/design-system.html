Màu icon
Dùng currentColor để icon kế thừa màu từ parent. Icon tương tác: --indigo-400. Icon phụ: --muted-foreground.
Stroke width
Luôn dùng 1.5px stroke cho size 16–24px. Có thể dùng 1px cho 12px và 2px cho 32px+ để giữ visual weight nhất quán.
Accessibility
Icon thuần trang trí: aria-hidden="true". Icon có nghĩa: thêm aria-label hoặc text ẩn kèm theo.
