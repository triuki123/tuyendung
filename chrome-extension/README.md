# AssetFlow CV Collector

## Cai dat tren Chrome

1. Mo `chrome://extensions`.
2. Bat **Developer mode**.
3. Chon **Load unpacked**.
4. Chon thu muc `chrome-extension` nay.
5. Ghim extension **AssetFlow CV Collector** len thanh cong cu.

## Su dung

1. Dang nhap AssetFlow tren Chrome.
2. Mo trang ho so ung vien ma ban co quyen truy cap.
3. Bam extension, kiem tra thong tin duoc nhan dien.
4. Bam **Mo form trong AssetFlow**.
5. Dinh kem file CV neu can, kiem tra trung va bam luu.

Extension khong luu mat khau, cookie hay token AssetFlow. Du lieu chi duoc dua vao form
AssetFlow sau khi nguoi dung chu dong bam nut.
